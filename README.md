# Лекция 05. Лямбда-функции и замыкания

Дисциплина CSE6742, Функциональное программирование. Швачкина Виктория.

В этом репозитории находится только работа по лекции 5. Все 14 примеров
исходной лекции и 4 задания самостоятельной работы выполнены. Отдельно
показаны три исправления позднего связывания и три исследования замыканий.
Всего 24 практических запуска, в каждом работают проверки assert.

Требуется Python 3.10 или новее. Внешние библиотеки не нужны.

```sh
python -X utf8 lecture.py --section all
python -X utf8 lecture.py --section srs2
python -X utf8 lecture.py --help
```

Запускайте без `-O`, иначе Python отключит assert. Полный запуск возвращает
код 0, если все проверки прошли. F(10), F(20), F(25) равны 55, 6765, 75025;
счётчик рекурсивных вызовов возвращает 177, 21891, 242785.

Отдельный отчёт Word с объяснениями, ответами на 10 вопросов и реальными
скриншотами передаётся преподавателю вместе с локальным комплектом.
Титульные листы и отчёты в этом публичном репозитории не размещаются.
